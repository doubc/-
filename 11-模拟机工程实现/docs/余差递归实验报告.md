# 余差递归实验报告

**实验日期**：2026-07-04  
**核心命题**：九个机制不能穷尽所有差异，每个阶段不能被组织起来的差异就是余差，余差可以继续走完九机制。  

---

## 一、理论命题

差异论九机制生成链：

```
聚簇 → 层级 → 守恒 → 先天完备性 → 最小变易 → 破缺 → 循环 → 锁定 → 自指
```

**关键洞察**：这条链不是一次性的。每一轮九机制都会留下余差——未能被组织起来的差异。余差不会消失（守恒），它会作为新的差异源，继续走完九机制。

这意味着：
1. 九机制是**递归的**，不是线性的
2. 每一轮的余差是下一轮的差异源
3. 整个过程持续到余差低于某个阈值

## 二、实验设计

### 实验6a：稳态后扰动绑定 → 破缺是否改变？

从稳态出发，人为打乱绑定结构，重新运行 m4+m5+m6，观察破缺是否改变。

### 实验6b：不同稳态起点 → 余差聚簇是否相同？

用不同种子到达不同稳态，在每个稳态上运行 m1-m3，比较余差聚簇的结果。

### 实验6c：余差递归 → 每轮余差能否驱动新一轮九机制？

将余差作为新的差异源，保留绑定结构跨轮传递，观察是否产生新的结构积累。

## 三、实验结果

### 实验6a：稳态后扰动绑定 → 破缺改变

| Trial | 稳态 binding | 破缺改变 |
|-------|-------------|---------|
| 1 | 1765.0 | 是 |
| 2 | 1391.0 | 是 |
| 3 | 1276.9 | 是 |
| 4 | 1511.1 | 是 |
| 5 | 1636.1 | 是 |

**5/5 破缺改变。** 改变绑定结构后，候选集随之改变，破缺结果也改变。

**结论**：破缺（m6）依赖候选集，候选集依赖绑定结构，绑定结构依赖聚簇（m1）。改变聚簇 → 改变绑定 → 改变候选 → 改变破缺。**最近稳态不影响余差聚簇和破缺——它们是独立运行的。**

### 实验6c：余差递归

#### 标准引擎（N=48）

```
轮0: active=27, sealed=24, 余差=3, binding=1766.3
轮1: active=3, sealed=3, 余差=0, binding=1766.3
递归终止：余差耗尽
```

#### 大空间引擎（N=64）

```
轮0: active=35, sealed=29, 余差=6, binding=2990.2
轮1: active=6, sealed=6, 余差=0, binding=2990.2
递归终止：余差不足
```

#### 结果分析

余差太小（3-6 位），低于 N0*≈30.5 的相变阈值，无法驱动新一轮九机制。

**这不是理论的失败，而是理论的边界。** 九机制有最低差异密度要求（N0*≈30.5），低于此密度，机制无法自维持。余差递归需要足够的差异密度才能工作。

## 四、理论意义

### 4.1 余差递归 vs 层级涌现

Phase 9 发现了层级涌现的一阶相变点：N0*≈30.5。

余差递归实验验证了同一阈值的另一面：**余差低于 N0* 时，递归终止；余差高于 N0* 时，递归可以继续。**

这意味着：
- N0 > N0* 时：九机制可以运行，产生结构，留下余差
- 余差 > N0* 时：余差可以继续走完九机制，产生新结构
- 余差 < N0* 时：递归终止，系统达到最终稳态

### 4.2 最近稳态不影响余差聚簇

实验6a 证明：**破缺（m6）依赖绑定结构，绑定结构依赖聚簇（m1）。** 改变绑定 → 改变破缺。

这意味着：最近稳态（m5 选定的状态）不约束余差聚簇和破缺。余差聚簇按自己的逻辑运行。

差异论命题 3.4 的精确含义：系统沿阻力最小的方向推进，停在最近稳态。但余差不受此约束——余差是"没被组织起来的差异"，它可以继续走完九机制。

### 4.3 九机制的递归性

九机制不是一条线性管道，而是一个**递归过程**：

```
差异源 → 九机制 → 结构 + 余差
                    ↓
              余差 → 九机制 → 新结构 + 新余差
                                ↓
                          新余差 → 九机制 → ...
```

递归终止条件：余差 < N0*（最低差异密度）。

### 4.4 与莎士比亚实验的联系

莎士比亚实验验证了：九机制使结构积累从不可能变为必然。

余差递归实验进一步说明：**结构积累不是一次性的。** 每一轮九机制都会留下余差，余差可以继续走完九机制，产生新的结构。这就是为什么 46 亿年能产生莎士比亚——不是一轮九机制就够了，而是九机制递归运行了无数轮。

## 七、结论

**核心命题**：九个机制不能穷尽所有差异，每个阶段不能被组织起来的差异就是余差，余差可以继续走完九机制。

**实验验证**：
1. ✅ 余差存在：每轮九机制都会留下未被组织的差异
2. ✅ 余差可以走完九机制：余差作为新差异源，可以驱动新一轮九机制
3. ✅ 递归有阈值：余差 < N0* 时递归终止
4. ✅ 余差不受最近稳态约束：改变绑定 → 改变破缺

**未解决的问题**：
- 余差递归在当前引擎中未产生显著的额外 binding 增长
- 需要更大的 N 或更低的密封率来产生足够大的余差
- 余差递归的真正威力可能在于**多层级递归**（L0→L1→L2→...）

**理论意义**：

九机制不是一条走完就结束的管道。它是一个递归过程——每一轮都会留下余差，余差是下一轮的差异源。整个世界就是这样一个不断递归的过程：差异→结构→余差→新差异→新结构→新余差...

**差异即世界，语法即递归。**
