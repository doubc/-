## 问题诊断

今日实验暴露了引擎的根本问题：

```
引擎在第 4 步后饱和（churn=0, flips=0）
    ↓
之后 2000 步全是被动积累（m1 聚簇、m8 锁定）
    ↓
余差递归无效（发生在第 100 步，引擎早已饱和）
    ↓
递归比例不影响 binding（因为引擎不再变化）
```

**根本原因**：m5（最小变易）的翻转动力来自守恒预算（budget），budget 来自 a1_source。一旦 a1_source 耗尽，budget=0，m5 就不再工作。

**理论诊断**：这不对。差异论说"差异不能被无代价清零"，但引擎的差异在第 4 步就被"清零"了——不是被消灭，而是被锁死。锁死不是守恒的本意。守恒的本意是差异会转移，不是差异会静止。

## 第一件事：内部张力驱动的 m5

### 理论依据

差异论命题 2.2："聚簇形成的结构，不只是差异的结果，它还会反过来重塑差异本身。"

聚簇不是终点。聚簇之间的边界会产生张力，张力积累到阈值时触发新的破缺。这就是为什么世界不是静态的——即使在"稳态"中，内部张力也在持续积累。

### 设计方案

```
当前 m5：
  a1_source → budget → 翻转
  问题：a1_source 耗尽 → budget=0 → 不再翻转

新 m5：
  a1_source → budget → 翻转（主动阶段）
  聚簇边界 → 张力 → 张力超阈值 → 翻转（被动阶段）
  
  两个驱动力并存：
  - 主动阶段：a1_source 注入新差异（前 4 步）
  - 被动阶段：聚簇内部张力驱动翻转（第 4 步之后）
```

### 张力的定义

```
tension(i) = Σ(binding[i,j] * |state[i] - state[j]|) for j in neighbors(i)
```

当某个位的张力超过阈值时，它被翻转。这模拟了"聚簇边界不稳定"的物理直觉。

### 预期效果

- 引擎不再在第 4 步饱和
- 张力持续积累，驱动持续的结构重组
- binding 增长曲线从"4 步后平坦"变为"持续增长"

## 第二件事：余差命运——递归 vs 噪声

### 理论依据

用户的修正："允许余差什么都不做。真实的宇宙也许是混沌的，只是无限多的随机中，局部完成了九机制这样的语法，并且稳定下来了。"

### 设计方案

每轮九机制结束后，余差按比例分为三类：

```
余差 = 活跃位 - 密封位
    ↓
递归余差（比例 p）：投入下一轮九机制
噪声余差（比例 1-p）：什么都不做，待在那里
```

参数 p 控制"语法的覆盖范围"：
- p=0：纯混沌，无结构
- p=0.1：10% 的差异被语法组织，90% 是混沌
- p=1.0：全部被组织（原始方案，不现实）

### 预期效果

- p=0 时，无结构积累
- p=0.1~0.5 时，局部结构岛出现
- p=1.0 时，全部被组织（理论上限）

**真实的宇宙大概在 p=0.01~0.1 之间**——绝大部分是混沌的，只有极小部分被九机制组织成结构岛。

## 第三件事：结构深度指标

### 理论依据

Shannon 熵无法区分噪声和结构。需要一个能衡量"组织深度"的指标。

### 设计方案

```
SD = binding_energy × lock_level × (sealed_fraction + ε)
```

- binding_energy：组织记忆
- lock_level：路径依赖
- sealed_fraction：不可逆程度

### 预期效果

- 猴子打印机：SD ≈ 0（无 binding，无 lock）
- 差异引擎：SD >> 0（有 binding，有 lock，有密封）
- 能够区分噪声复杂度和结构复杂度

## 实施顺序

```
1. 内部张力驱动的 m5  ← 最关键，解决引擎饱和
2. 余差命运（递归 vs 噪声）  ← 依赖第 1 步
3. 结构深度指标  ← 独立，可并行
```

先做第 1 步。第 1 步做好了，第 2 步才有意义。第 3 步可以同时做。

## 理论修正

今日实验带来的一个重要理论修正：

**原命题**：九机制是世界的全局语法。
**修正后**：九机制是世界的局部语法。大部分世界是混沌的。九机制只在差异密度超过 N0* 的局部生效，形成结构岛。结构岛在混沌海洋中自维持。

**差异即世界，语法即局部。**
